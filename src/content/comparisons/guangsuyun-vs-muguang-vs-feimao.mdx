## 核心定位与客户端自由度拆解（决定淘汰谁的第一关）

很多新手选机场时只看价格和“香港延迟 20ms”，买完后才发现自己的 iPhone 小火箭或 OpenWrt 软路由根本导不进去。在光速云、暮光加速、飞猫云这三家中，**第一道硬筛选门槛就是客户端模式**。

### 1. 光速云：同时吃下“小白自研”与“极客订阅”两端需求

光速云（`proprietary_and_third_party`）采取的是当前兼容面最广的双轨制：
- 如果你是第一次接触代理工具，不想自己折腾 Clash YAML 配置文件，可以直接安装官方自研客户端登录使用；
- 如果你习惯了桌面端 [Clash Verge Rev](/guides/clash-verge-rev-beginner-guide/)、**FlClash**、**v2rayN**，或手机端 iOS [Shadowrocket 小火箭](/guides/shadowrocket-ios-setup/)，以及家里部署了 [OpenWrt 软路由](/guides/openwrt-router-proxy-guide/)，光速云也完整开放第三方订阅导入，且原生采用 **VLESS / Shadowsocks / AnyTLS** 现代协议栈。

### 2. 飞猫云：彻底放弃第三方订阅的极简主义

飞猫云（`proprietary_only`）在产品设计上走了另一条极端简洁的路径：**不提供 Clash、Shadowrocket 等任何第三方订阅链接**，用户只能在 Windows / macOS / iOS / Android 上安装飞猫云专属客户端登录使用。
- **优点**：完全消灭了“订阅链接转换失败”“Clash 内核版本太旧报错”“规则分流配错导致国内网站卡顿”等新手 90% 的售后痛点。
- **代价**：你无法把它装进 OpenClash / Nikki 软路由做全屋电视/主机透明代理，无法和手里其他机场的节点写进同一个策略组自动容灾，也无法针对某一个冷门 AI 域名手动写覆写规则。

### 3. 暮光加速：全平台覆盖但协议与订阅透明度待核实

暮光加速在品牌资料中强调支持 Windows、macOS、iOS、Android 与 Linux 五大平台且允许“多设备同时在线”，定位偏向个人多终端协同与小型远程团队。但相比光速云明确列明 VLESS/SS/AnyTLS 与第三方订阅入口，暮光加速在现有资料中**既未单列具体传输协议，也未明确是否完全开放第三方 Clash 订阅链接**（档案标记为 `unverified`），注重自定义配置的用户下单前需向其 7×24 客服二次确认。

## 实测证据完整度与 2026 测速数据硬核拆解

评判机场不能只看厂商自述表格，必须把三家实际公开可查的网络测试档案拿出来逐一审计。在这一点上，三家拉开了非常清晰的梯度差距。

### 1. 光速云：三网 + 9Gbps 单线程 + 5Gbps 32 线程（证据最厚实）

光速云在数据库中共留存了 **6 张不同日期与运营商环境的原始实测图**，以及 `2026-10-19` 清单非晚高峰基准：
- **2026-08-19 珠海联通 9Gbps 单线程 VLESS（70/70 节点）**：注意这是极考验单连接上限的**单线程**测试，香港平均 **375–424 MB/s**、新加坡 **220–315 MB/s**、美国 **313–370 MB/s**，且多数节点 UDP 类型显示为 **FullCone**。
- **2026-08-19 三网 2Gbps 6 线程实测（62/62 节点）**：
  - 长沙电信 2Gbps：日本均值 **49.38 MB/s**，香港专线 TLS RTT 稳定在 **20–31ms**；
  - 广西移动 2Gbps：新加坡均值 **53.12 MB/s**（峰值 **56.53 MB/s**）；
  - 河北联通 2Gbps：新加坡均值 **41.85 MB/s**，但部分香港节点 HTTPS 延迟升高至约 `1200ms`，提示北方联通用户使用光速云时应优先切至新加坡或日本节点。
- **2026-08-11 14:32:56 CST MAI-TEST-BOT（Shadowsocks，珠海联通 5Gbps 32 线程）**：除了 `HK02` 实测为 `0B`，港/新/日/美均值落在 **54–75 MB/s**。
- **2026-10-19 清单非晚高峰基准**：香港 `22ms / 529Mbps`、台湾 `41ms / 114Mbps`、新加坡 `46ms / 387Mbps`、日本 `57ms / 135Mbps`、美国 `143ms / 18Mbps`。

### 2. 飞猫云：具备 08-11 早间截图，但缺多运营商与晚高峰验证

飞猫云目前拥有 **1 张实测图**（`2026-08-11 08:52:30 CST`，MAI-TEST-BOT Shadowsocks 32 线程）与 `2026-10-19` 非晚高峰基准：

- **关键缺口**：缺少晚上 20:30–22:30 高峰时段截图，且缺乏电信/移动分网测速与独立流媒体解锁截图。

### 3. 暮光加速：仅有 10-19 非晚高峰清单基准，尚无独立实测截图

## 三家客户端迁移与多设备协同实操注意

选定品牌之后，日常使用中的“设备切换便利度”往往决定了你会不会在一个月后弃坑。以下三点是三家在真实多端落地时最需要注意的工程细节：

1. **同时用电脑、iPhone 与软路由的混合环境**：如果你家里已经刷了 OpenWrt（OpenClash / Nikki / PassWall2），或者手机常驻 Shadowrocket / Stash，那么 **只有光速云（支持第三方 Clash/Shadowrocket 订阅且不限设备）能无缝打通全部终端**；暮光加速需要先向客服确认订阅格式是否开放第三方导入；飞猫云则只能分别在每台电脑和手机上装官方客户端，客厅电视盒与旁路由无法直接接管。
2. **光速云多节点切区实战**：因为 `2026-08-19` MiaoKo 解锁实测图明确显示光速云的香港节点对 OpenAI 仅限 APP 模式、对 Gemini 不可用，且部分台湾节点曾出现 YouTube 送中或 Disney+ 失败，建议导入 Clash Verge Rev 后直接加一条规则覆写，把 `ChatGPT` 与 `Gemini` 域名指向 **新加坡或马来/日本策略组**，把 `YouTube / Disney+` 指向 **香港或美国/日本节点**，即可一次配置长期省心。
3. **专属客户端（飞猫云）与自研端版本维护**：使用飞猫云专属客户端时，遇到 Windows 系统更新或 macOS 升级大版本后，若发现系统代理未自动恢复或无法上网，先检查软件内“系统代理 / TUN 模式”开关是否被重置，并前往官网下载对应架构的最新安装包覆盖更新。

### Q2. “每月重置流量”与“一次性不限时流量包”到底怎么选更划算？

这两类套餐本质上是“包月流量卡”和“永不清零预付卡”的区别，可以通过一个简单公式判断——**看你每月的真实稳定消耗是否超过 25GB**：

- **每月重置型（适合中高频用户）**：每月到了结算日（或自然月 1 号）流量清零并重新下发全额配额，当月没用完的 GB **不会结转累积到下个月**。如果你每天看 YouTube 1080P/4K、用 AI 编程、更新大型海外开发依赖，每月用量轻松超过 50–150GB，买月付（¥20/月 120–150GB）或品牌年付（¥96–¥137/年）每 GB 单价只需 **¥0.12–¥0.17/GB**，非常划算。
- **一次性不限时流量包（适合低频用户与应急备用）**：买下后账户里有一笔固定总流量（例如 100GB 或 247GB），只要账号处于正常状态，**用 1GB 少 1GB、不按月清零**。

用真实数据算一笔账：假如你每个月只查资料、收邮件、偶尔问几次 ChatGPT，消耗只有 **10GB/月**。如果你买 ¥25/月的包月套餐，一年要花 300 元；而如果买 **[光速云 147 元 247GB 永久套餐](/brands/guangsuyun/)**（约 ¥0.60/GB）或 **[二猫云 99 元 100GB](/brands/ermao/)**、**[星岛梦 100 元 100GB](/brands/xingdaomeng/)**、**[一翻云 100 元 100GB](/brands/yifan/)**、**[唯兔云 100 元 100GB](/brands/weitu/)**，这 100GB 足够你用满整整 10 个月，247GB 甚至能用两年！此外，不限时包更是防范主力机场突然失联的完美“备用保底”。

### Q3. 为什么结账时输入优惠码提示无效或不能用于年付/永久包？

绝大多数服务商都会把**本就利润极薄的年付小包、限时特价档或永久流量包**排除在通用优惠码之外。在我们的 31 家品牌审计中就有多处明确规定：
1. **明确排除入门/永久档**：光速云的“轻量版（99元/年）”和“147 永久套餐”明确不参与常规折扣；**Firefly** 的 `firefly` 8 折码与 **闪跃** 的 `shanyue` 8 折码明确标注“年付版不适用”；**灵猫网络** 的 `lingmao` 8 折码同样标注“年付小包不适用”。
2. **历史文档双码版本差异**：部分品牌在不同时期的推广文档或汇总表里出现过两个代码（例如一翻云记录有 `1FLYYUN` 与 `yfy6666`，全球云记录有 `qq88` 与 `qqy7777`，隐形人记录有 `moon80` 与 `yxr888`，暮光加速记录有 `muguang5555` 与无公开活动说明）。
**操作建议**：结账时务必点击结算页的“验证/应用优惠码”，以页面最终显示的实付金额为准，切勿凭印象扫码。

## 二、流量倍率与扣费统计（Q4–Q6）

### Q4. 节点标注的“1x 倍率”和“2x / 0.5x 倍率”怎么计算扣费？

节点名称末尾常见的 `1x`、`×1`、`1.5x`、`2x`、`0.5x`，就是该条线路的**流量扣费乘数**。计算公式为：`后台实际扣除流量 = 真实经过该节点传输的流量 × 节点倍率`。

| 节点倍率标记 | 你实际下载了 10GB 视频 | 后台套餐额度实际扣除 | 100GB 套餐真实可用量 | 常见原因与选节点建议 |
| :--- | :--- | :--- | :--- | :--- |
| **`0.5x`（低倍率）** | 10GB | **5GB** | 相当于 200GB | 多为冷门直连或闲置大带宽节点，适合下载大文件省流量 |
| **`1x` / `×1`（标准倍率）** | 10GB | **10GB** | **实打实 100GB** | **目前主流优质专线主流标准**（如光速云、星岛梦、唯兔云、无忧、灵猫均标全节点 1x） |
| **`1.5x` / `2x`（高倍率）** | 10GB | **15GB / 20GB** | 缩水为 50–66GB | 高成本稀有专线或游戏加速/家宽独享节点；日常刷网页注意避开 |
| **`3x` / `5x`（超高倍率）** | 10GB | **30GB / 50GB** | 缩水为 20–33GB | 极少数高成本落地，**切忌用来挂机下载或看 4K 视频** |

> 特别提醒：部分低价高容量广告（比如“20元500GB”）如果暗藏 `2x` 或 `3x` 主力节点，实际可用量往往不如另一家“20元150GB 但全节点 `1x`”的套餐耐用。详细分析可见 [性价比机场深度拆解](/articles/cost-effective-airport-pricing-analysis/)。

### Q5. 后台显示的“已用流量”为什么比我手机/电脑统计的下载量多？

很多用户觉得自己只下载了一个 1GB 的安装包，结果机场后台却扣了 1.3GB 甚至 2GB，怀疑服务商“偷跑流量”。排除 `2x` 倍率外，正常的技术差额通常来自以下三点：
1. **双向流量合计（上行 + 下行）**：机场计费统计的是**上传流量 + 下载流量的总和**。你视频通话、同步网盘、发送图片或 Git Push 都会产生上行消耗。
2. **误开全局模式（Global）**：如果客户端开成了全局代理而非规则分流（`Rule`），你打开国内 B 站、百度网盘、腾讯视频甚至 Windows 系统更新都会走代理节点，流量会在毫无察觉的情况下飞快蒸发。
3. **协议加密开销与弱网 TCP 重传**：TLS 握手、加密头封装会产生约 5%–10% 的额外字节；在信号极差的地铁/高铁里频繁丢包重传，也会放大实际转发的总包量。

## 三、设备并发与防滥用风控（Q7–Q8）

### Q7. “不限设备数量”真的可以全宿舍或几十个人共用一个账号吗？

**绝对不行！** 在 31 家品牌中，光速云、星岛梦、一翻云、唯兔云、二猫云、U1S1、无忧链接、灵猫网络、Firefly、SOGO 云等均标注“不限设备数量”或支持多设备同时在线。但它的真实含义是：**不限制你个人名下的电脑、手机、iPad、备用机和家里路由器同时挂着使用**。

几乎所有机场后台审计系统都有**并发 IP 数量与异常流量阈值风控**。如果你把一条订阅链接直接发在宿舍群、甚至转卖给不同城市、不同宽带运营商的几十个人使用，后端一旦检测到同一个账号同时从十几个不同的公网 IP 源源不断发起高并发连接，轻则自动踢线限速，重则直接判定“商业合租/公开泄露”并永久封停账号且不予退款。**如果全家人或同居室友在同一个家庭路由器 Wi-Fi 下通过软路由（OpenClash / PassWall2）共享，出口公网 IP 只有 1 个，这属于完全正常的个人/家庭用法。**

### Q8. 换新手机或重装电脑后，订阅还能用吗？需要重置订阅链接吗？

1. **换机或重装系统**：完全不影响使用。只需要在新设备上装好客户端（如 Clash Verge Rev 或 Shadowrocket），登录机场官网重新复制一次订阅地址导入即可。如果是带有“设备绑定数量限制”的少数特定客户端机场，去官网控制面板里把旧设备踢下线或解绑即可。
2. **何时必须点击“重置订阅链接（Reset Token）”**：一旦你怀疑订阅链接曾经发给过别人、在公共电脑上忘记退出后台、或者发现后台流量在自己完全没开机时莫名其妙被消耗，请立刻登录机场官网个人中心点击**“重置订阅链接”**。重置后旧链接即刻作废，你需要把新生成的订阅地址重新覆盖导入自己手上的设备。

## 四、客户端兼容与协议选择（Q9–Q11）

### Q9. 自研客户端机场和开放 Clash / 小火箭订阅的机场有什么本质区别？

两者的核心差异在于**软件控制权与生态扩展性**，详见 [传统商业 VPN、自研端与 Clash 对比指南](/articles/vpn-vs-airport-proxy-guide/)：
- **仅专属客户端机场**（目前包括飞猫云、SOGO 云、隐形人、Firefly、无忧链接、灵猫网络、全球云、闪跃）：服务商把节点、分流规则和登录鉴权全部打包在官方 App 里。优点是**完全零配置、下载输入账号密码就能连**；缺点是无法导入 iOS 小火箭（Shadowrocket）、电脑 Clash Verge Rev 或 OpenWrt 软路由，也无法把两家机场合并在同一个软件里做分流。
- **双支持或通用订阅机场**（如光速云、梯子云、速界、极连云、光年梯、星岛梦、一翻云、微风网络、唯兔云、可信云等）：既能配合自研端（部分品牌）也能导出订阅给社区开源客户端。最大好处是**不绑定软件、可精细自定义 AI 分流规则、可随时挂载备用机场**。

### Q10. 我买了好几家机场，能同时导入同一个 Clash Verge Rev 或小火箭里吗？

**完全可以，而且这正是推荐的“主备防断流”高级用法。**
- **在 Clash Verge Rev / FlClash 中**：你可以在「订阅（Profiles）」页面同时粘贴 A 机场和 B 机场的订阅链接。日常保持点击激活主力 A 机场；一旦 A 机场出现波动，点一下 B 机场的配置文件即可 1 秒切换，无需重新配置软件。进阶用户还可以使用 Mihomo 的 `proxy-providers` 合并订阅功能，把两家节点放进同一个规则列表里。
- **在 iPhone Shadowrocket（小火箭）中**：点击右上角 `+` 可以不断添加多个 `Subscribe（订阅）`，所有机场的节点都会按组折叠显示在首页，点击哪家节点就走哪家的流量，切换极其直观。

### Q11. 为什么导入订阅后节点全部不显示、或者一连就 Timeout？

遇到导入订阅后一片空白或节点全部超时，按下面四步排查 99% 能解决（完整排错见 [节点 Timeout 与订阅失败修复指南](/guides/node-timeout-dns-fix/)）：
1. **内核版本过老（最常见原因）**：原版 Clash for Windows / Clash for Android 早已停止维护，**完全不支持 VLESS-Reality、Hysteria 2 与 AnyTLS 协议**。当你导入一翻云、光速云、微风网络等包含 VLESS 或 HY2 节点的订阅时，旧内核会直接过滤掉无法识别的节点，导致列表为空。请更换为基于 **Mihomo** 或 **sing-box** 的新版客户端（如 Clash Verge Rev、FlClash、Hiddify、Karing，详见 [客户端总览](/clients/)）。
2. **系统时间误差超过 90 秒**：VMess、VLESS、Trojan 与 TLS 握手对本地设备时间非常敏感。如果你的 Windows 电脑因为双系统或主板电池问题慢了几分钟，所有节点都会直接连接失败。打开系统设置点击“立即同步网络时间”即可。
3. **订阅地址被本地网络污染导致下载失败**：部分国内宽带环境下无法直接拉取订阅链接，可以请拥有代理网络的环境帮忙更新，或在机场官网切换备用订阅域名，详见 [订阅获取失败排查指南](/guides/subscription-failed-troubleshooting/)。
4. **个别节点临时维护（0B 状态）**：如我们在 `2026-08-11` 多家实测截图看到的，同一家机场 50–70 个节点中偶尔出现 1–2 个编号（如 HK01/HK02）临时维护掉线是正常现象，换到同地区其他编号节点（如 HK03–HK10）即可恢复。

## 五、国内分流、延迟与测速图解读（Q12–Q14）

### Q12. 开着代理会影响国内微信、淘宝、B 站或国服网游速度吗？

不会，前提是你选对了**分流模式**：
- **规则模式（Rule / 配置 Config）**：这是所有成熟客户端的默认推荐模式。客户端通过内置的国内域名表（Geosite-CN）与国内 IP 段（GeoIP-CN）做匹配——访问淘宝、微信、抖音、百度网盘、国服游戏时直接走本地宽带（`DIRECT`），**不仅不会变慢，也不消耗任何机场流量**。
- **全局模式（Global / Proxy）**：所有流量不分青红皂白全部塞进海外节点。如果你发现开着代理后国内网页转圈、微信图片加载慢、淘宝提示异地风控，99% 是不小心点成了全局模式。
- **公司内网 / NAS 访问异常补充**：如果你在规则模式下依然打不开公司内网 OA 或家庭局域网 NAS，通常是 DNS 模式选了 `Fake-IP` 导致内网域名解析冲突。按 [Mihomo DNS 解析指南](/articles/clash-meta-mihomo-dns-guide/) 将公司内网域名加入 `fake-ip-filter` 跳过列表，或切换为 `Redir-Host` 模式即可解决。

### Q13. 客户端测速延迟显示 30ms 和 300ms、或者显示 Timeout 代表节点坏了吗？

新手最容易过度迷信客户端自带的“一键延迟测速数字”，实际上需要分清客户端在测什么：
1. **TCP Ping vs URL Test（HTTP/HTTPS Ping）**：
   - 在 **2026-08-19 光速云 MiaoKo 实测**中，长沙电信测香港专线的 **TLS RTT** 只有 `20–31ms`，这个数值主要反映你本地宽带连上国内中转入口再完成加密握手的物理耗时；
   - 而 **URL Test / HTTPS 延迟** 测的是“从你电脑出发 → 经国内入口 → 跨境专线 → 海外落地 → 访问海外目标网页（如 Google generate_204）再返回”的完整往返耗时，因此通常会显示 `120ms–350ms` 左右（甚至美国节点显示 `200–400ms`）。**这是完全正常的体感流畅区间**，不要拿海外网页往返延迟跟国内打王者荣耀的 20ms 去比！
2. **显示 Timeout 并不总是节点死了**：如果同时对 60 个节点并发测速，本地网络瞬间拥堵或者某个节点恰好屏蔽了测速目标网址，也会显示超时。最准确的验证方式是**选中节点，真实打开一个 4K YouTube 视频看缓冲条或看客户端实时网速曲线**。

### Q14. 为什么别人测速图能跑 400 MB/s，我自己回家用只有 15 MB/s？

读懂测速图（完整教程见 [手把手看懂 MiaoKo 测速图](/guides/how-to-read-miaoko-speedtest/)）必须先看懂三个物理边界：
1. **单位差 8 倍**：测速软件常用的单位是 **MB/s（兆字节每秒）**，而电信/联通宽带办理时说的是 **Mbps（兆比特每秒）**，换算关系是 **`1 MB/s = 8 Mbps`**。如果你家里办的是 100Mbps 宽带，理论下载天花板本来就是 `12.5 MB/s`；办的是 300Mbps 宽带，天花板是 `37.5 MB/s`。你跑出 `15 MB/s`（相当于 `120 Mbps`）其实已经跑满了百兆宽带！
2. **测试服务器带宽与线程数不同**：例如在 `2026-08-19` 光速云实测中，**珠海联通 9Gbps（9000Mbps）机房单线程**跑出了香港 `375–424 MB/s`、美国 `313–370 MB/s`；而同日 **2Gbps 6 线程**三网测试中，广西移动新加坡均值是 `53.12 MB/s`、长沙电信日本均值是 `49.38 MB/s`。顶级数据中心机房跑出的极限数值，仅用来衡量“机场跨境专线本身有没有瓶颈”，并不等于你家手机 Wi-Fi 也能跑到 400 MB/s。
3. **测试时间与运营商差异**：很多测速图是在白天非晚高峰测的（例如 08-11 批次有 `00:21`、`08:52`、`14:38` 等多种时段），且北方联通与南方电信到同一家机场入口路由不同——例如 08-19 实测中河北联通连部分香港节点 HTTPS 延迟升高至 `1200ms+`，但切到新加坡均值就有 `41.85 MB/s`。

## 六、AI 与流媒体地域解锁（Q15–Q16）

### Q15. 为什么香港节点延迟最低、看剧最快，用 ChatGPT 和 Gemini 却老报错？

因为 **OpenAI、Claude 和 Google Gemini 都对香港地区 IP 实施了不同程度的区域限制**，这在我们的实测中得到了最直接的印证（详见 [AI 与流媒体解锁指南](/articles/ai-and-streaming-unlock-guide/)）：
- 在 **2026-08-19 光速云 70 节点 MiaoKo 实测**中，20 个香港专线节点全部返回 OpenAI **`仅 APP(HK)`**——即手机官方 App 勉强可用，电脑浏览器打开直接受限；而日本、新加坡、美国绝大多数节点都是完整网页解锁。
- 对于 **Google Gemini**，同一份 70 节点测试中，香港、日本、美国、台湾节点大面积失败，只有**新加坡部分节点、马来西亚和土耳其节点**通过检测。
- 在 **2026-07-20/21 灵动云 60 节点测试**中，虽然 OpenAI 各地区解锁很强，但也存在 TikTok 多失败和港外亚洲部分节点异常的问题。

**正确用法**：不要用全局切节点，直接在 Clash Verge Rev / Stash / Shadowrocket 的 `proxy-groups` 里把 **日常网页默认保留在香港专线**，把 **OpenAI / Claude 单独分流到新加坡、日本或美国（优先 `IPRisk: LOW` 节点）**，把 **Gemini 单独指向实测有效的新加坡/马来节点**。

### Q16. 什么是 YouTube“送中(CN)”以及 Netflix/Disney+ 节点地区漂移？

- **YouTube 送中(CN)**：指某个海外落地服务器的 IP 因为被大量国内定位请求污染，被 Google 地理库反查标记成了中国大陆（`CN`）。例如在 **2026-07-18 无忧链接 50 节点御三家测试**中，虽然全部 50 个节点都解锁了 Netflix 和 Disney+，YouTube 也解锁了 49 个，但 `香港HKG - 01` 就出现了 `送中(CN)` 标记；在 **2026-08-19 光速云**测试中，部分新加坡和台湾节点也出现过 `送中(CN)`。送中节点会导致 YouTube 地区标识消失、Premium 后台失效及 Gemini 报错，遇到直接拉黑切到同区其他编号节点即可。
- **地区漂移（落地误识）**：例如在 **2026-07-20/21 灵动云**实测中，台湾落地节点被 Netflix 和 Disney+ 识别成了 `ES`（西班牙/欧洲区）。这多因服务器使用了跨区广播 IP 所致，虽然能看剧但看不了目标本地限定片库，遇到此类情况直接切换香港、日本或新加坡常规原生节点观看。

## 七、付款、售后退款与防跑路止损（Q17–Q18）

### Q17. 刚买的机场连不上或速度慢，能申请全额退款吗？

**现实情况是：绝大多数跨境代理服务不支持无理由退款。**
数字订阅链接一旦生成并下发，用户即可消费流量且存在订阅 token 复制留存问题，因此行业内普遍采用“特殊商品/数字虚拟服务不退不换”原则（我们在光速云、无忧链接等资料审计中也明确注明了特殊商品不支持退款或无免费试用限制）。

**因此把“买前试错成本”压到最低比买完找客服扯皮重要得多**：
1. 首次下单任何一家机场，**坚决先选最低价月付档**（18–25 元），哪怕只用一个月觉得不合本地宽带，损失也只有二十元左右；
2. 如果你习惯先看真实数据再买，优先筛选带有完整实测截图（2026-08-19 / 08-11 / 07-18）且资料透明、不回避短板的品牌；
3. 切勿因为客服口头说“稳如狗”“包解锁一切”就直接充一年甚至三年付。

### Q18. 遇到官网打不开、订阅更新失败或疑似服务商失联怎么办？

千万不要第一时间在客户端里删掉原有订阅（否则连最后能用的几个残留节点缓存也没了），按以下三步冷静处置：
1. **利用现存节点更新面板**：国内部分网络环境会对机场官网主域或订阅链接做间歇性拦截。在客户端里先连上一个目前还能通的节点（哪怕慢一点），打开浏览器访问机场官网发布页或后台面板，检查是否发布了新的备用域名或新的订阅地址。
2. **排查是不是停运跑路前兆**：如果全线节点持续 Timeout 超过 48 小时、官方工单无人回复、公告频道彻底断更，或者此前突然出现过“199 元终身无限流量”疯狂清仓促销，高度怀疑跑路停摆（详见 [跑路预警与低价陷阱指南](/articles/airport-pricing-trap-guide/)）。此时应立刻停止续费并放弃等待。
3. **3 秒启用“不限时备用包”无缝接管**：这也是我们反复强调**“月付主力 + 99–147 元不限时备用包”**架构的原因——只要你平时在 Clash Verge Rev 或 Shadowrocket 里预先存好另一家独立品牌的不限时流量包，随时点一下切换即可恢复联网，根本不用慌张去网上乱找危险的免费节点。

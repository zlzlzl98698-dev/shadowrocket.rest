## 一、第一阶段：客户端形态决策树（自研专属 App vs 通用第三方订阅）

在逛任何一家机场官网之前，你必须先回答一个最关键的问题：**我以后打算用什么软件来连网？** 根据本站截至 2026-11 对 31 家品牌的核查，市面上的机场服务商按客户端策略明确分为三大阵营：

### 1.1 三大客户端阵营与真实代表品牌

1. **双支持阵营（自研客户端 + 第三方订阅兼备）**
   - **特点**：既提供官网一键登录的专属软件，也开放标准订阅链接供 Clash / Shadowrocket 导入。**新手容错率最高**，前期不想折腾可以先用官方端，熟悉以后随时无缝切换至开源客户端。
   - **数据库代表**：[光速云](/brands/guangsuyun/)、[梯子云](/brands/tiziyun/)、[速界](/brands/sujie/)、[二猫云](/brands/ermao/)、[大佬云](/brands/dalaoyun/)、[闪电鼠](/brands/shandianshu/)、[极连云](/brands/jilian/)、[光年梯](/brands/guangnian/)。
2. **仅通用第三方订阅阵营（必须自备 Clash / 小火箭等客户端）**
   - **特点**：不开发自家套壳 App，专注做好线路与标准订阅输出，用户生态自由度极高，可配合多机场订阅合并、分流规则、软路由透明代理。
   - **数据库代表**：[星岛梦](/brands/xingdaomeng/)、[微风网络](/brands/weifeng/)、[一翻云](/brands/yifan/)、[唯兔云](/brands/weitu/)、[可信云](/brands/kexin/)、[U1S1](/brands/u1s1/)。
3. **仅专属客户端阵营（下载官网 App 登录即用，不提供订阅链接）**
   - **特点**：零学习成本，账号密码登录即可开关节点，不需要理解什么是 YAML、内核或端口；**缺点是完全无法导入 Clash Verge Rev、iOS Shadowrocket 或 OpenWrt 软路由**，且若官方客户端在 iOS 端需要共享海外 Apple ID 或企业签名，长期灵活性受限。
   - **数据库代表**：[飞猫云](/brands/feimao/)、[SOGO 云](/brands/sogo/)、[隐形人](/brands/yinxingren/)、[全球云](/brands/quanqiu/)、[闪跃](/brands/shanyue/)，以及**自 2026 年 10 月起停止提供订阅、全面转向专属客户端的 [灵猫网络](/brands/lingmao/)、[无忧链接](/brands/wuyou/) 与 [Firefly（萤火虫）](/brands/firefly/)**。

### 1.2 新手客户端决策树（30 秒锁定方案）

请顺着以下问题往下对照，不要跨路线混选：

- **问题 1：你是否要在 iPhone / iPad 上使用已购买的 Shadowrocket（小火箭）/ Stash，或在路由器（OpenWrt）上运行 OpenClash / PassWall2 / Nikki？**
  - **是** → **绝对排除“仅专属客户端”阵营**，只能从「双支持」或「仅通用第三方订阅」阵营选择。
- **问题 2：你是否希望完全不接触“订阅 URL”“Rule 规则模式”“Mihomo 内核”这些概念，只求电脑/手机装个软件输入账号就能开开关？**
  - **是** → 优先在「双支持」（如梯子云、光速云）或「仅专属客户端」（如飞猫云）中选择。推荐优先看“双支持”，给自己留一条日后进阶的后路。
- **问题 3：你是否有 Linux 无桌面开发机、Mac M 系列芯片或多设备并发需求？**
  - **是** → 选择提供通用订阅的协议透明型品牌（支持 VLESS / Trojan / HY2），并在桌面端安装原生跨平台开源客户端（如 Clash Verge Rev 或 FlClash）。

## 二、第二阶段：提前备好正版客户端与防钓鱼核心自检

如果你走的是“通用第三方订阅”或“双支持”路线，**务必在购买机场套餐之前，先把客户端装到设备上**。这样不仅能避免买完订阅后慌张乱搜软件踩坑，还能直接检验自己设备的系统架构。

### 2.1 全平台正版开源/商店客户端推荐表

基于本站 [全平台客户端大全](/clients/) 整理，各平台公认安全且仍在积极维护的首选工具如下：

| 操作系统 | 推荐首选客户端 | 底层内核 | 官方安全获取渠道 | 特别安全避坑提醒 |
| :--- | :--- | :--- | :--- | :--- |
| **Windows 10/11** | **Clash Verge Rev** / **FlClash** / **v2rayN** | Mihomo / Xray / sing-box | GitHub Releases 官方仓库 | 原版 Clash for Windows 已删库停更；远离百度竞价里带“高速下载器”的中文站，核对 `x64` vs `arm64` |
| **macOS** | **Clash Verge Rev** / **FlClash** | Mihomo | GitHub Releases 官方仓库 | M1/M2/M3/M4 芯片选 **`aarch64.dmg`**，老款 Intel 芯片选 **`x64.dmg`**；遇 Gatekeeper 提示按规范放行 |
| **Android** | **v2rayNG** / **FlClash** / **Hiddify** / **Karing** | Xray / Mihomo / sing-box | GitHub Releases / 官方应用页面 | **严禁在 Google Play 下载已被第三方控制的同名 NekoBox**；安装后将 App 加入系统电池优化白名单 |
| **iOS / iPadOS** | **Shadowrocket（小火箭）** / **Stash** / **Karing** | 自研 / Clash 兼容 / sing-box | **外区（如美区）App Store** | 切勿使用来路不明的第三方企业签名抓包安装；外区商店 Shadowrocket 为一次性买断付费应用 |
| **Linux 桌面 / 服务器** | **Clash Verge Rev**（桌面）/ **v2rayA**（无桌面） | Mihomo / Xray | GitHub Releases / 发行版仓库 | 区分 `.deb` / `.rpm` / `.AppImage`；无图形界面主机用 `v2rayA` Web 控制台 |

### 2.2 识别假冒下载站与钓鱼面板的五个红灯信号

1. **域名拼装怪异或出现在中文搜索引擎“广告”位**：任何以中文关键词拼凑的所谓“Clash Verge 中文官方下载网”“小火箭电脑破解版免费下”，100% 非开源团队官方站点。完整验证步骤与 PowerShell / `shasum` 哈希校验命令，请务必读完 [Clash Verge 下载安全核验与防假冒指南](/articles/clash-verge-download-and-verify/)。
2. **安装包体积异常（几十 KB 到 2MB 的下载器）**：正常包含 Mihomo 内核与图形界面的桌面安装程序体积通常在 **20–40MB** 以上，遇到 `Clash_Setup_Downloader.exe` 这种微型引导器直接关闭删除。
3. **要求关闭杀毒软件或安装系统根证书（CA）**：正规开源代理软件无需向系统写入陌生 CA 根证书；一旦弹出“为了加速请信任安装安全证书”，立即终止。
4. **机场官方域名地址栏检查**：注意部分老旧机场面板的推广注册链接如果结构异常（例如我们在 [品牌资料审计情报](/articles/brand-data-audit-summary/) 中披露的云界线与环球梯缺少 `#` 号），打开后需观察页面是否完整渲染出注册表单和域名归属，再决定是否输入邮箱注册。
5. **非官方途径售卖“内置永久节点破解版”**：凡是声称花 9.9 元买断软件永久免费用节点的网盘链接，本质上都在窃取他人订阅或植入远控木马。

## 三、第三阶段：下单与结账前的七项硬核核对清单

挑好 1–2 个候选品牌进入官网注册页准备付款时，请对照下表逐项过关，任何一项没看清都先不要输入支付密码：

### 核对 1：分清“年付折算月均价”与“单月起购价”

几乎所有宣传“5.6 元/月”“7 元/月”“8 元/月”的套餐，**都是年付入门包除以 12 个月的折算成本**，而不是可以按月付 7 元买一个月：
- [光速云](/brands/guangsuyun/)：轻量版 ¥99/年（折合 ¥8.25/月，69GB/月）；单月购买极速版 ¥25/月（168GB/月）。
- [微风网络](/brands/weifeng/)：清风 ¥137/年（约 ¥11.42/月，100GB/月）；单月购买乘风 ¥27/月（200GB/月）。
- [飞猫云](/brands/feimao/)：学生版 ¥84/年（折合 ¥7/月，50GB/月）；单月购买星耀版 ¥25/月（150GB/月）。
- 5.6 元档（[闪电鼠](/brands/shandianshu/)、[大佬云](/brands/dalaoyun/) 等）：均为年付折算价（约 ¥67.2/年，60GB/月），且缺独立测速报告。

### 核对 2：首单必须“先月付或小包试错”，绝不盲目买多年付

中国大陆不同省市的电信、联通、移动宽带（尤其是家宽与校园网）连接到同一家机场入口 BGP 的路由质量差异极大。别人白天在珠海联通 5Gbps 环境下跑出 90 MB/s 的节点，放到你家晚高峰移动宽带上可能会因为跨网拥堵而卡顿。**加上绝大多数机场在条款中注明“特殊虚拟商品不支持退款”，首次购买唯一稳妥的做法是先花 18–25 元买一个月付档**，跑满一两周晚高峰确认流畅后，再考虑季付或年付折扣。

### 核对 3：核对协议与客户端内核是否匹配

目前 31 家品牌主力采用的协议已经全面升级：
- 若目标品牌采用 **VLESS / XTLS-Reality / Hysteria 2 / AnyTLS**（例如一翻云支持 HY2 与 VLESS-Reality，光速云支持 VLESS 与 AnyTLS，微风、速界、可信云、光年梯采用 VLESS），你的客户端**必须基于 Mihomo（原 Clash.Meta）或 sing-box/Xray 内核**（如 Clash Verge Rev、FlClash、v2rayN、Shadowrocket 最新版）。如果你电脑里还留着 2023 年停更的原版 Clash for Windows，导入后会发现节点全空或报错。
- 若目标品牌采用 **Trojan 或 Shadowsocks**（如星岛梦、唯兔云采用 Trojan），兼容性最广，几乎所有主流客户端均可解析。
- 具体协议区别可参阅 [VLESS、Trojan 与 Hysteria 2 协议对比](/articles/vless-vs-trojan-vs-hy2/)。

### 核对 4：看清流量倍率、设备在线限制与重置周期

- **倍率陷阱**：确认全节点是否为 **1x（1 倍率）**。部分机场普通节点 1x，但写着 `IPLC` 或 `原生解锁` 的节点标注 `2x` 或 `3x`，意味着你看 1GB 视频会扣掉 3GB 账户流量。
- **设备限制**：虽然光速云、星岛梦、一翻云、二猫云、唯兔云、U1S1、灵猫网络、无忧链接、SOGO 云、Firefly 等大多标称“不限设备数”，但“不限个人多端同时在线”不等于允许把订阅发给十几个陌生人共享，异常高频异地 IP 并发仍会触发封号风控。
- **重置周期**：注意流量是“每月 1 号统一重置”还是“按购买日每 30 天滚动重置”；如果买的是“一次性不限时包”（如光速云 ¥147/247GB、星岛梦 ¥100/100GB），则不按月清零、用完为止。

### 核对 5：核对优惠码适用条件与双版本记录

新手最常问“为什么填了优惠码提示无效或没减钱？”原因通常有三点：
1. **特殊低价档与年付小包排除折扣**：例如光速云「致敬斯诺克 147 永久包」与「99 元轻量版」不参与常规折扣；灵猫 8 折码 `lingmao` 不适用 85 元年付小包；Firefly `firefly` 与闪跃 `shanyue` 均明确注明**年付版不适用**；
2. **存在双版本优惠码记录**：如本站在 [品牌资料审计情报](/articles/brand-data-audit-summary/) 中核查到的，一翻云（`1FLYYUN` vs `yfy6666`）、SOGO 云（`SOGO10000` vs `sss777`）、全球云（`qq88` vs `qqy7777`）、隐形人（`moon80` vs `yxr888`）等存在两套历史代码记录，结账时需现场试测实际减免金额；
3. **付款周期门槛**：如 5.6 元档标注“季付及以上 7 折”，月付本身不触发该折扣。

### 核对 6：查看数据可信度分级，避开信息黑箱

在挑选候选品牌前，去数据库看一眼它的 `dataStatus` 标签：有 **2026-08-11 / 08-19 实测截图** 的品牌（18 家），至少能看到真实节点数量、延迟分布和是否存在 `0B` 死节点；而标为 `historical` 或明确缺乏测速数据的品牌（如浪网、EdgeNova、隐形人等），切勿仅凭宣传语就购买长周期大额套餐。

### 核对 7：注册账号的隐私隔离原则

1. **绝不复用国内重要平台密码**：使用浏览器密码管理器或随机字符串生成一个**仅用于该机场面板的独立高强度密码**。
2. **使用常用且收信稳定的邮箱（或独立小号邮箱）**：便于后续找回密码与接收节点域名变更通知，避免填错邮箱或使用过几天就销毁的临时一次性邮箱导致忘记密码无法申诉。
3. **保存好官网备用导航页**：防止主面板域名日后遇阻失联。

## 四、第四阶段：购后首次连网标准化操作流

付完款进入机场用户仪表盘（Dashboard）后，按以下标准流程完成首次接入，全程通常只需 3 分钟：

### 4.1 桌面端（以 Clash Verge Rev 为例）

1. **退出冲突软件**：先确认电脑没有同时运行其他 VPN、代理工具或网游加速器。
2. **同步系统时间**：右键桌面右下角时间 →「调整日期和时间」→ 点击 **「立即同步」**（macOS 在「系统设置 → 通用 → 日期与时间」开启自动设置）。这一步能提前消灭 70% 的新手首连失败。
3. **获取并导入订阅**：
   - 在电脑自带默认浏览器（Chrome / Edge / Safari）登录机场后台，找到「一键导入」或「复制 Clash 订阅链接」按钮。
   - **最佳实践是点击「复制订阅地址」**，切开 Clash Verge Rev 左侧「订阅（Profiles）」栏，在顶部输入框粘贴 URL 后点击「导入（Import）」。
   - 导入完成后，**务必在列表中左键单击选中刚导入的那条配置卡片**（确认其处于高亮激活状态），不要还停留在空白默认配置上。
4. **选择代理模式与开启开关**：
   - 点击左侧「代理（Proxies）」，在顶部确认模式为 **「规则（Rule）」**（不要选全局 Global，否则国内软件全部绕道海外极慢还浪费流量；也不要选直连 Direct）。
   - 展开策略组（通常叫 `Proxy` / `节点选择` / `自动选择`），点击右侧闪电/测速图标执行一次 URL-Test 延迟测速，挑选一个延迟低于 100ms 且非超时的香港/新加坡/日本节点。
   - 回到左侧「设置（Settings）」，打开 **「系统代理（System Proxy）」** 开关；如果还需要让终端命令行（Git / pip / npm / Docker）或不支持系统代理的桌面软件走代理，再按教程安装服务模式并开启 **「TUN 模式」**（详见 [Clash Verge Rev 新手教程](/guides/clash-verge-rev-beginner-guide/)）。

### 4.2 移动端（以 iOS Shadowrocket 小火箭为例）

1. 在 Safari 浏览器（不要用微信内置浏览器）登录机场后台，点击「导入到 Shadowrocket」或复制通用订阅链接。
2. 打开 Shadowrocket → 右上角 `+` → 类型选择 **「Subscribe（订阅）」** → 粘贴 URL → 备注填机场名称 → 点击右上角保存。
3. 下拉列表刷新订阅获取节点后，在首页把 **「全局路由（Global Routing）」设置为「配置（Config）」**（即按规则分流，千万别选“代理”全全局或“直连”）。
4. 点击「连通性测试（Ping）」，选中有效节点后打开顶部总开关；首次开启 iOS 会弹窗请求「添加 VPN 配置」，点击允许并输入锁屏密码即可上线。完整细节可查阅 [Shadowrocket 小火箭 iOS 完整配置教程](/guides/shadowrocket-ios-setup/)；安卓用户可查阅 [Android 安卓代理客户端教程](/guides/android-proxy-clients-guide/)。

## 七、第七阶段：新手首连高频故障速查矩阵（7 问 1 分钟自救）

刚上手前三天最容易碰到以下七种报错，先按本表自救，95% 不需要苦等工单客服：

1. **症状：所有节点测速全部红字 `Timeout`（超时）**
   - **首要原因**：电脑/手机系统时间慢了或快了超过 1 分钟；或者本地同时开着其他 VPN/网游加速器。
   - **1 分钟修复**：同步操作系统时间 → 彻底退出其他加速器 → 在客户端点击刷新一次订阅。
2. **症状：复制订阅点击导入报错 `403 Forbidden`、`Failed to fetch` 或超时**
   - **首要原因**：在微信内打开链接被拦截，或机场主面板当前处于墙外/需启用客户端的「绕过代理更新」选项。
   - **1 分钟修复**：把订阅链接复制到记事本检查前后有没有多余空格；若是更换过电脑网络，尝试切换手机热点拉取一次订阅；详见 [订阅拉取失败排查指南](/guides/subscription-failed-troubleshooting/)。
3. **症状：关闭代理软件后，整个电脑打不开任何国内网站（连微信也掉线）**
   - **首要原因**：上次电脑直接关机或软件异常闪退，Windows/macOS 系统代理里残留了 `127.0.0.1:7897`（或 `7890`）指向已退出的端口。
   - **1 分钟修复**：重新打开一次客户端，把「系统代理」开一下再**手动关掉**，然后正常退出软件；或者进入系统「网络与 Internet → 代理」关闭手动代理开关（详见 [关闭 Clash 后断网修复](/guides/node-timeout-dns-fix/)）。
4. **症状：开启 TUN 模式后，公司内网 OA、NAS 或局域网打印机打不开**
   - **首要原因**：部分老旧内网客户端不兼容默认的 `Fake-IP` 虚拟网段（`198.18.0.0/16`）。
   - **1 分钟修复**：在客户端设置里把 DNS 模式切换为 `Redir-Host`，或者将公司内网域名加入 `fake-ip-filter` 绕过列表。
5. **症状：iPhone 小火箭顶部显示已连接（VPN 图标出现），但 Safari 一直转圈打不开网页**
   - **首要原因**：节点本身已过期/流量耗尽、全局路由误选了不支持的规则、或者本地同时开启了 iCloud 专用代理/第三方广告拦截 VPN 冲突。
   - **1 分钟修复**：在 Shadowrocket 底部「设置 → 延迟测试方法」设为 `CONNECT`，测试节点是否有数字；关闭其他冲突 VPN 配置。
6. **症状：Android 安卓手机锁屏 5 分钟后自动断网，解锁重新进 App 才恢复**
   - **首要原因**：国产手机系统激进的省电策略杀死了后台代理进程。
   - **1 分钟修复**：在手机系统设置里将 v2rayNG / FlClash / Hiddify 设为 **“允许后台高耗电 / 无限制省电策略”**，并在多任务界面下拉锁定该应用。
7. **症状：没怎么看视频，后台流量却飞速减少**
   - **首要原因**：网盘同步（OneDrive/Google Drive/iCloud）、Steam/Epic 游戏自动更新、或 Windows Update 在挂着“全局模式”或高倍率节点时全速跑在后台。
   - **1 分钟修复**：确保始终处于「规则（Rule）」模式，大文件下载和游戏更新前手动切换到低倍率或直连节点，并检查机场后台是否包含 `2x/3x` 高倍率节点。
